# OEM Guardrails

Mark a scenario `OEM_DEPENDENT` when:

- the launcher role or default-home chooser is blocked by OEM UX
- system settings surfaces vary and EasyUI still provides honest guidance
- background process behavior depends on manufacturer task management

Mark a scenario `OUT_OF_SCOPE_BY_PRODUCT_GUARDRAIL` when it depends on:

- device-owner lockdown
- notification-shade blocking
- enterprise kiosk behavior
- remote caregiver control
