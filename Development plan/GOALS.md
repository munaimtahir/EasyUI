# Goals

## Product goals

### MVP goals
1. Replace the default home experience with a senior-friendly launcher.
2. Deliver a visibly simpler and more readable UI than standard Android home screens.
3. Ensure the product works completely offline.
4. Make first-run setup clear enough that a caregiver can configure it without confusion.
5. Keep the daily experience stable and low-friction.

### v1.0 goals
1. Add a compelling premium caregiver safety pack.
2. Reduce accidental layout changes through edit locking and hidden caregiver settings.
3. Let caregivers hide distracting or dangerous apps from the visible interface.
4. Provide direct-call photo contacts for family and doctors.
5. Add backup and restore of launcher configuration.

## User goals

### Senior user goals
- Find main apps quickly
- Make calls easily
- Avoid getting lost
- Read labels and targets comfortably
- Use the phone without fear of breaking something

### Caregiver goals
- Set up the phone once with minimal effort
- Prevent accidental interface changes
- Keep only the right apps visible
- Restore the setup easily if something changes
- Feel confident that the launcher is stable and safe

## Business goals
- Reach early niche traction through caregiver-focused positioning
- Convert free users to a one-time premium unlock
- Keep support burden low
- Avoid backend infrastructure costs
- Build a trustworthy utility product with strong reviews

## Metrics
- Day-1 successful setup completion rate
- Percentage of users who set EasyUI as default launcher
- Premium conversion rate
- 30-day retention
- Crash-free sessions
- Review sentiment around setup simplicity and caregiver value
