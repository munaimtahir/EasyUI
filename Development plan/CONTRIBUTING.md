# Contributing

## Principles
- Protect simplicity
- Protect accessibility
- Protect trust
- Protect offline behavior
- Protect product honesty

## Pull request rules
- small focused changes preferred
- include acceptance notes
- include tests when behavior changes
- update docs when scope or UX changes
- avoid unrelated refactors mixed with product work

## Review questions
1. Does this make the launcher easier or harder for seniors?
2. Does this reduce or increase caregiver support burden?
3. Does this preserve stable behavior?
4. Does this keep the product honest about its capabilities?
5. Is there a simpler way to achieve the same value?

## Coding style
- choose clarity over abstraction
- avoid premature optimization
- use consistent naming
- keep UI copy plain and human
