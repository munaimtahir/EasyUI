# Product Brief

## Product name
EasyUI Senior Launcher

## One-line description
A simple Android home screen for seniors, with caregiver controls that reduce confusion and accidental changes.

## Core problem
Modern Android phones are visually dense and easy to disrupt accidentally.
Seniors may:
- tap the wrong thing
- move icons by mistake
- struggle to read labels
- get lost in app clutter
- accidentally open confusing apps or settings

This creates frustration for the user and repeated support burden for caregivers.

## Core solution
Replace the normal Android home screen with a senior-friendly launcher that:
- shows only what matters
- uses large buttons and clear text
- keeps the layout stable
- lets caregivers lock editing and hide confusing apps

## Primary users
Seniors who need a simpler interface.

## Primary buyers
Adult children, caregivers, and family members who set up the device.

## Main user value
- easier phone use
- less confusion
- bigger, clearer controls
- less accidental damage to layout
- easier calling of important people

## Main buyer value
- fewer support calls
- cleaner setup
- stable phone experience
- peace of mind

## Core emotional promise
The phone stops feeling stressful.
