# Monetization Strategy

## Model
Freemium with one-time premium unlock.

## Why this model
The buyer is usually a caregiver who wants peace of mind, not a power user looking for endless monthly features.
A one-time purchase is easier to understand and easier to trust.

## Free tier
- senior-friendly launcher
- large icons and labels
- simplified app list
- flashlight shortcut
- emergency call shortcut
- basic theme option

## Premium tier
- PIN-protected caregiver mode
- layout lock
- hide apps
- pinned photo contacts
- backup/restore layout
- premium visual options
- caregiver setup tools

## Pricing direction
One-time purchase in the range of:
- entry option: low-mid tier
- premium unlock: standard caregiver peace-of-mind price point

## Avoid at launch
- recurring subscription
- ad-heavy monetization
- confusing upgrade structure
