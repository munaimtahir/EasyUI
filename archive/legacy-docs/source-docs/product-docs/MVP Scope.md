# MVP Scope

## MVP objective
Ship a useful senior launcher quickly with a clear visible difference from the default Android experience.

## Must-have features

### 1. Launcher replacement
- App can be set as the device home launcher
- Clear first-run instructions for setting it as default

### 2. Simple home screen
- Large icon tiles
- Large text labels
- High contrast design
- Clean spacing
- Minimal clutter

### 3. Simple app access
- Straightforward app list
- Alphabetical sorting
- No folders
- No complex widgets
- No confusing page swipes required for basic use

### 4. Essential actions
- flashlight shortcut
- emergency call shortcut
- direct call button area for important contact(s)

### 5. Offline-first behavior
- no account required
- no cloud sync required
- app fully usable offline

### 6. Accessibility basics
- large font support
- strict contrast
- simple theme options
- easy touch accuracy

## MVP design principles
- one obvious action per area
- no hidden complexity
- no decorative overload
- no fragile layout behavior

## Explicitly out of MVP
- notification shade blocking
- true system lockdown
- device-owner mode
- advanced kiosk features
- remote caregiver control
- backend account system
- subscriptions
- ads
