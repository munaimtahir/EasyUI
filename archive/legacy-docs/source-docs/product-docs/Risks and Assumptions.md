# Risks and Assumptions

## Key assumptions
- caregivers are the main decision-makers
- users value simplicity over flexibility
- one-time payment is more suitable than subscription
- offline-first architecture improves trust and lowers maintenance

## Main risks
### 1. Wrong positioning
If the app is marketed as full lockdown, expectations will become unrealistic.

### 2. Weak differentiation
Large icons alone are not enough.
The product must win on caregiver stability features.

### 3. Over-expansion
Adding too many options will make the launcher less senior-friendly.

### 4. OEM inconsistency
Launcher behavior and default-app flows vary across Android devices.

## Mitigation
- honest promise
- strong setup guidance
- clear premium value
- keep product narrow and stable
