# Version 1 Scope

## Goal
Add the caregiver features that justify payment and create a stable long-term product.

## Strongly recommended v1 features

### Caregiver safety controls
- PIN-protected edit mode
- lock icon positions
- prevent accidental rearrangement
- optional disable long-press editing

### App visibility control
- hide unused or confusing apps
- show only selected apps on home/app list
- optionally hide settings from normal view

### Contacts and quick access
- pinned photo contacts
- doctor/family direct call tiles
- large photo-based shortcuts

### Stability tools
- layout backup/restore
- restore default layout
- caregiver reset tools

### Interface options
- light theme
- dark theme
- battery visibility toggle
- simple unread or attention indicator styling

## Nice to have in v1 if feasible
- medication reminder shortcut integration
- missed call visibility on home screen
- larger dialer shortcut area
- caregiver onboarding wizard
