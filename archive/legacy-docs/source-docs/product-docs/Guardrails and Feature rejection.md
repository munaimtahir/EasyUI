# Feature Rejection and Guardrails

## Features rejected for now
- system-level notification shade disable
- guaranteed settings restriction at OS level
- enterprise kiosk promises
- device policy enforcement for consumer devices
- cloud account dependency
- remote web dashboard
- user syncing across multiple devices
- AI chat assistant inside launcher
- feature-heavy widgets
- complex gesture systems
- ad-supported clutter

## Guardrails
- Do not market the app as full lockdown
- Do not imply enterprise device management
- Do not depend on manufacturer-specific hacks as core promise
- Do not add features that make setup harder for caregivers
- Do not prioritize customization over stability

## Product truth
This app simplifies the home experience and reduces common accidental changes.
It does not fully control Android system behavior across all consumer devices.
