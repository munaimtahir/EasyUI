# Project Brief

## Product name
EasyUI Senior Launcher

## One-line description
A simple Android home screen for seniors, with caregiver controls that reduce confusion and accidental changes.

## Problem
Modern Android phones are visually dense, easy to disturb by mistake, and often difficult for seniors to use confidently. Common problems include:
- accidental icon movement
- confusion caused by app clutter
- difficulty reading labels
- accidental opening of unfamiliar apps
- repeated support calls to caregivers

## Solution
Provide a replacement launcher with:
- large, clear touch targets
- stable layout
- simplified app access
- emergency shortcuts
- caregiver PIN-protected edit controls
- hidden confusing apps
- photo contact shortcuts

## Primary buyer
Adult children, caregivers, or family members who set up and maintain the device.

## Primary user
Older adults with reduced vision, reduced touch precision, low smartphone confidence, or mild confusion with complex smartphone interfaces.

## Product philosophy
- Simplicity before power
- Stability before customization
- Trust before growth hacks
- Offline-first by default
- Honest technical boundaries
- Low-maintenance architecture

## Non-goals
This product is not:
- a full device lockdown system
- an enterprise kiosk app
- a parental control tool
- a remote management platform
- a cloud-heavy service

## Monetization
Freemium with one-time premium unlock:
- Free: core senior-friendly launcher
- Premium: caregiver safety pack

## Success condition
The caregiver can configure the phone once, hand it over, and receive fewer support calls because the layout stays stable and the daily interaction is clear.
