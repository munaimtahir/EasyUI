# Privacy Policy Final

## EasyUI Senior Launcher

Effective date: March 16, 2026

EasyUI Senior Launcher is designed to work offline and store its setup information on the device.

## What EasyUI stores on your device

EasyUI may store the following information locally on the device:

- home screen tile layout and ordering
- caregiver settings such as layout lock and readability choices
- caregiver PIN salt and hashed PIN value
- hidden-app preferences used inside EasyUI
- favorite contact names, phone numbers, and selected photo URI references
- onboarding completion status

This information is used only to run EasyUI on the device.

## What EasyUI does not do

Based on the current app build, EasyUI does not:

- require an account
- operate its own cloud sync service
- send personal data to an EasyUI backend
- include ads
- include analytics SDKs
- include crash-reporting SDKs
- sell or share personal information for advertising

## Device features used

EasyUI can:

- list launchable apps installed on the phone so it can show them in the launcher
- open the phone dialer when an emergency or favorite contact tile is tapped
- toggle the flashlight on supported devices
- let the user choose a contact photo through the system document picker

EasyUI does not place calls automatically. It opens the system dialer so the action can be reviewed before calling.

## Backup

Automatic Android backup is disabled in the current release build. This release does not provide cloud backup.

## Third-party services

The current build does not include third-party analytics, advertising, or crash-reporting services.

## Your choices

You can remove EasyUI's locally stored data by uninstalling the app or clearing app storage through Android settings.
