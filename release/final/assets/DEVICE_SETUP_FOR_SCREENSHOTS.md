# Device Setup For Screenshots

1. Use one clean Android phone or emulator in portrait orientation.
2. Set large system font and display size.
3. Use a bright wallpaper-free or neutral wallpaper-free state if possible.
4. Set battery to a normal level and avoid notification clutter.
5. Use sample contact names only.
6. Install a small set of common apps so `All Apps` looks realistic.
7. Make sure EasyUI onboarding starts from a clean app install before capture.
8. Do not show personal phone numbers, email addresses, or real contact photos.
