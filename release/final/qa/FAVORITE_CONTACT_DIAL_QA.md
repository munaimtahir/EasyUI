# Favorite Contact Dial QA

1. Open `Caregiver Tools`.
2. Open `Manage Favorite Contacts`.
3. Add one sample contact.
4. Return to the home screen and tap that contact tile.
5. Confirm the system dialer opens with the number filled in.
6. Confirm the call is not placed automatically.

Pass if the dialer opens correctly and EasyUI never auto-calls.
