# Manual Phone QA

Run these on one real Android phone before submission.

1. Install the release build and confirm the app opens cleanly.
2. Complete onboarding and verify `Set EasyUI as Home` is understandable.
3. Set EasyUI as the default launcher and confirm Home opens normally.
4. Tap several home tiles and confirm no crashes.
5. Open `All Apps`, search, and launch an app.
6. Open `Caregiver Tools` and verify the screen loads without visual breakage.
7. Run the focused checks in the files below.
8. Reboot once and confirm EasyUI still opens correctly.

If any of these fail, treat it as a release blocker until explained.
