# Default Launcher Flow QA

1. Fresh install the release build.
2. Open EasyUI and go through `Start Setup`.
3. From `Set EasyUI as Home`, open Android default app settings.
4. Set EasyUI as the home app.
5. Return to EasyUI and confirm the app reports the launcher state correctly.
6. Press Home and confirm EasyUI appears instead of the old launcher.

Pass if the flow is understandable and Home consistently opens EasyUI afterward.
