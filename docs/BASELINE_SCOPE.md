# Baseline Scope — EasyUI

This document defines the product scope for **EasyUI**, a senior/caregiver smartphone product. EasyUI is built on top of the frozen **Core Launcher** foundation, which resides in a separate repository. EasyUI is an intentional product derivative of Core. Therefore, Core's original product-variant and caregiver prohibitions do not govern EasyUI. Caregiver monitoring, a supporting backend service, and a senior-friendly launcher are fully valid within-scope capabilities of EasyUI.

## In Scope for EasyUI

### 1. Senior Launcher App (`:senior-launcher`)
- **Accessible Layout**: High-contrast, large text, and large touch targets (minimum 48dp).
- **Core Launcher Actions**: Functions as default Android HOME, discovers installed apps, lists apps alphabetically, launches apps on tap.
- **Home Tiles**: Fixed grid (2x2, 3x3, 4x4) displaying pinned favorite apps and built-in shortcuts (dial, SMS, battery status, local reminders, Clock/Date, Note).
- **Caregiver PIN & Lockout**: Secure caregiver area protected by SHA-256 salted PIN. Lockout behavior prevents brute-force (30 seconds lockout after 5 failures).
- **Emergency / SOS Screen**: Press-and-hold (2 seconds) button that triggers a direct dial call to caregiver/911 and posts an SOS alert to the backend.
- **Voluntary Check-In**: "I'm OK" button that posts a check-in status timestamp and message to the backend.
- **Local Reminders**: Add, view, delete, and alert local reminders. Allows receiving reminder suggestions pushed by a paired caregiver.
- **Privacy & Trust Center**: Visual card detailing what data is shared, active permissions granted to caregiver, generate/display pairing code, and disconnect caregiver (revocation).

### 2. Caregiver Companion App (`:caregiver-companion`)
- **Secure Pairing**: Enter an 8-character pairing code generated by the senior launcher to establish a secure link.
- **Seniors Overview**: View battery level, charging status, and last seen timestamp of the linked senior.
- **Check-in Log**: View the latest voluntary check-in timestamp and message sent by the senior.
- **Alerts Log**: View active emergency alerts (like SOS triggers) with timestamp details.
- **Suggested Reminders**: Stage suggested reminders (title, type, time) and push them to the senior launcher.
- **Settings & Disconnect**: Clear session token and disconnect device link.

### 3. Backend Gateway Orchestrator (`:backend`)
- **Token Authentication**: Secure Ktor bearer authentication requiring a valid device token.
- **Pairing Orchestration**: Temporary pairings generator and code validator `/initiate-pairing` and `/pair`.
- **Data Cache Routes**: Store and serve device status, check-ins, alerts, and pending suggested configurations.

---

## Out of Scope for EasyUI Baseline

The following capabilities are excluded from the current baseline:

- **Android System UI Replacement**: EasyUI does not replace the real Android status bar, OEM notification shade, or Android Quick Settings.
- **Mobile Data & Wi-Fi Restrictions**: EasyUI does not directly restrict Wi-Fi or mobile data access at the system level.
- **Full Device Lockdown**: EasyUI does not claim enterprise MDM control, kiosk owner lockdown, or restricted settings blocking outside the launcher.
- **Monetization**: No ads, subscriptions, payment integration, or licensing checks.
- **Cloud-only dependency**: The senior launcher must remain completely functional local-first. Network connectivity failures must not cause crashes or prevent local launching, local calling, local reminders, or local SOS.
