# Known Limitations (Alpha Release)

Please be aware of the following limitations in this Alpha version of EasyUI:

1. **Not a Lockdown App:** EasyUI simplifies the main phone experience but does not fully lock Android. Seniors can still swipe down to access the notification shade and quick settings.
2. **Device Variations:** Setting the Default Home App differs by brand (Samsung vs Xiaomi vs Google). EasyUI attempts to guide you, but you may need to manually search your phone's settings for "Default Apps" if the automatic prompt fails.
3. **Sharing Status:** The "Tell Caregiver" remote link feature requires a sharing app to be installed (like WhatsApp, Messages, or Gmail) to send the link.
4. **Battery Optimizations:** Some manufacturers (like vivo or Xiaomi) have aggressive background battery optimizations that might close EasyUI or delay background health checks.
5. **Alpha Software:** This is an early test version. Minor visual glitches or unexpected behaviors may occur.
