# EasyUI Caregiver Setup Guide (Alpha)

Welcome to the EasyUI Alpha! Your role is to set up the phone so your loved one can use it safely.

## Key Steps
1. **The PIN:** The 4-digit PIN you create during setup is the key to unlocking "Caregiver Tools". Do not share this with the senior if they are prone to accidentally changing settings.
2. **Hidden Apps:** Go to Caregiver Tools -> Hidden Apps. Hide any apps that might confuse the senior (e.g., system updaters, complex banking apps they don't use, bloatware).
3. **Emergency Contact:** Ensure the primary emergency contact is accurate. This is the big red button on their home screen.
4. **Layout Lock:** Once you have the home screen arranged perfectly, use the "Lock Layout" toggle in Caregiver Tools so icons can't be accidentally dragged around.

## What if things break?
If the phone loses internet or EasyUI stops being the default launcher, a warning card will appear on the senior's screen. They can tap "Get Help" or "Open Setup Status", which provides you with buttons to quickly fix the issue.
