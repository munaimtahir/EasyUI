# EasyUI Alpha Installation Steps

1. **Download the APK:** Transfer the `EasyUI-Senior-Launcher-v0.1.0-alpha01-signed-alpha.apk` file to the target Android phone.
2. **Enable Unknown Sources:** If prompted, allow your browser or file manager to "Install unknown apps" in Android Settings.
3. **Install:** Tap the APK file to install EasyUI.
4. **Open EasyUI:** Once installed, tap "Open".
5. **Complete Guided Setup:** Follow the on-screen instructions to set up the caregiver PIN, emergency contacts, and allowed apps.
6. **Set as Default Home App:** During setup, when prompted to "Set EasyUI as Home", click the button and select EasyUI (and choose "Always").
7. **Test the Home Button:** Press your phone's physical or on-screen Home button. It should return you to the simple EasyUI screen.
8. **Test Critical Features:** Tap "Emergency", "Phone", and "More Apps" to ensure they open correctly.
9. **Report Issues:** Use the provided feedback forms to report any crashes or confusion.
