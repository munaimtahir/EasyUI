# Release Scope - EasyUI V1.5 Signed Alpha

This release packages the EasyUI Senior Launcher for initial real-world distribution to a limited group of caregiver/senior testers.

## Included in this release
- All core senior launcher features (V1.1-V1.4).
- Hardened Intent handling (Safe Handoffs).
- Robust Default Launcher activation strategies (RoleManager, Fake Launcher).
- Proactive Phone Health monitoring.
- Caregiver Dashboard (Hidden Apps, Layout Lock, PIN).
- Remote Link status sharing.

## Excluded from this release
- Automated crash reporting (Crashlytics).
- Play Store Billing/Premium features (running in completely free mode).
- OS-level lockdown (Kiosk mode).
