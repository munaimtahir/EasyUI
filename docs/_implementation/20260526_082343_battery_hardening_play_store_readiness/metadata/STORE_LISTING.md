# Play Store Listing Metadata - EasyUI

## App Title
EasyUI Senior Launcher

## Short Description
A simple, stable, and safe phone screen designed for seniors and managed by caregivers.

## Full Description
EasyUI is an offline-first Android launcher that simplifies the smartphone experience for seniors. It replaces the complex standard interface with a high-contrast, large-button layout that prioritizes what matters most.

### Key Features:
- **Large Targets:** Big buttons for Phone, Messages, and Photos to reduce accidental taps.
- **Caregiver Managed:** A protected dashboard allows caregivers to set up the phone once and lock the layout.
- **Hidden Apps:** Hide complex or distracting apps from the senior's view while keeping them installed on the device.
- **Phone Health Alerts:** Proactive warnings for low battery, lost internet, or home screen changes.
- **Assisted Recovery:** One-tap fixes for common issues, guided by simple instructions.
- **Offline-First:** Your data stays on your phone. No accounts, no cloud sync, no tracking.

EasyUI is designed to give seniors independence while giving caregivers peace of mind.

## Data Safety Summary
- **No Data Collected:** EasyUI does not collect or share any user data with third parties.
- **No Internet Required:** Core functionality works entirely offline.
- **Permissions:** Standard permissions used for calling and app management only.
