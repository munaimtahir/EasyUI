# Listing Graphics Prompts

Use these prompts to generate Play Store listing assets that match the current product: calm, high-contrast, caregiver-friendly, and honest. Do not imply kiosk control, remote monitoring, or enterprise device management.

## Visual Direction

- warm neutral background, not pure white
- high contrast text
- large readable UI
- clear rectangular tiles with generous spacing
- calm, trustworthy tone
- no purple-heavy startup-app aesthetic
- no futuristic dashboard metaphors

## Icon Prompt

Create a clean Android launcher app icon for "EasyUI Senior Launcher". Show a simple home-screen grid with large rounded tiles, a calm warm background, and one subtle caregiver-friendly accent. The icon should feel trustworthy, minimal, readable, and senior-friendly. Avoid tiny details, lock icons, shield clichés, enterprise branding, and dark cyber aesthetics. Deliver in a polished Play Store-ready style.

## Feature Graphic Prompt

Create a Google Play feature graphic for "EasyUI Senior Launcher". Show a calm Android launcher experience for seniors with large readable tiles, simple labels, and a caregiver-friendly setup feel. Use warm neutral tones, strong contrast, and a clean composition with generous whitespace. Include subtle visual cues for clarity, stability, and safety, but do not imply remote control, device lockdown, or medical diagnosis. The image should feel premium, honest, and easy to trust.

## Screenshot Frame Prompt

Create polished phone screenshot mockups for an Android senior launcher. Keep the UI large, legible, uncluttered, and high contrast. Show realistic launcher screens with big tiles, caregiver-friendly settings, and calm spacing. Use modern editorial typography and a warm, reassuring visual tone. Do not show widgets, ads, remote dashboards, or kiosk-style restrictions.

## Suggested Screenshot Set

1. Home screen
   - headline: `Large buttons for everyday essentials`
   - show: six-tile home, calm background, readable clock, strong spacing
2. Onboarding
   - headline: `Easy setup for caregivers`
   - show: default launcher guidance or caregiver help
3. Caregiver settings
   - headline: `Keep the layout steady`
   - show: PIN, layout lock, hidden apps, battery toggle
4. Safety tools
   - headline: `Emergency, Health Info, and SOS`
   - show: emergency settings or Health Info screen
5. Backup and restore
   - headline: `Move setup to another phone`
   - show: backup/restore screen

## Negative Prompt Guidance

Avoid:

- enterprise dashboards
- map views
- caregiver remote-control panels
- chatbots or AI assistants
- surveillance framing
- medical-monitoring claims
- cluttered icon walls
- tiny labels
