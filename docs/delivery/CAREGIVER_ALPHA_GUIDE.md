# EasyUI Caregiver Alpha Guide

Welcome to the EasyUI Senior Launcher Alpha! This guide helps you set up and maintain a stable, simple phone experience for your loved one.

## 1. Initial Setup
- **Set as Default:** During setup, ensure you set EasyUI as the "Default Home App". This ensures the phone always returns to the simple screen when the Home button is pressed.
- **PIN Protection:** Create a 4-digit PIN. This prevents accidental changes to the layout or settings by the senior.

## 2. Managing Apps
- **Home Screen Tiles:** You can assign up to 12 apps (6 per page) to the main home screen. Choose the most essential ones (e.g., Phone, WhatsApp, Camera).
- **Hidden Apps:** Use the "Hidden Apps" setting in Caregiver Tools to remove complex or distracting apps from the "All Apps" list.

## 3. Helping from Afar (Remote Link)
- **Share Status:** Use the "Alert Caregiver" button on the senior's phone to send a status update to your phone via WhatsApp or SMS.
- **Battery & Connection:** You can see the senior's battery level and Wi-Fi status directly in the shared status link.

## 4. Troubleshooting (Assisted Recovery)
- If something goes wrong (e.g., Wi-Fi is off or EasyUI is no longer the default), a **warning card** will appear on the senior's home screen.
- Tap the card to open **Assisted Recovery**, which provides simple buttons to fix common issues.

## 5. Feedback
Please report any crashes, confusing text, or "traps" where the senior gets stuck in the system Android interface.
