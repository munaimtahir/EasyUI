# Asset Capture Plan

## Scope

This plan is for `EasyUI Senior Launcher`. No Play-ready screenshots or feature graphic source assets currently exist in the repository, so this file defines the capture set rather than faking assets.

## Screenshot set

Use a clean device or emulator with large system font enabled and a realistic senior-focused setup.

### Phone screenshots

1. Intro screen
   - Show the first-run message and product name.
   - Goal: communicate simple setup and senior focus.

2. Default launcher guidance
   - Show the screen that explains how to set EasyUI as the home app.
   - Goal: make the launcher role explicit for Play reviewers and users.

3. Home screen
   - Show large tiles, clock/date, and caregiver entry point.
   - Goal: demonstrate readability and low clutter.

4. App list
   - Show alphabetical app list with search populated.
   - Goal: show that hidden complexity is still reachable through a simple list.

5. Caregiver tools
   - Show the protection and home stability status cards.
   - Goal: demonstrate caregiver value without implying remote control.

6. Favorite contacts
   - Show favorite contact tile setup with photo selection state.
   - Goal: show quick access to important people.

7. Home readability
   - Show readability presets and very simple mode.
   - Goal: communicate accessibility-focused customization.

8. Hidden apps or reset safety screen
   - Show one safety-focused caregiver management screen.
   - Goal: reinforce stability and reduced accidental changes.

## Capture guidance

- Use portrait orientation.
- Avoid exposing personal data in screenshots.
- Use realistic sample contact names and app labels.
- Keep status bar clean and battery/time reasonable.
- Do not capture OEM settings pages unless they are necessary for the launcher guidance screenshot.
- Do not claim system lockdown or device-owner control in overlay text.

## Feature graphic specification

Since no feature graphic source asset exists in the repo, create one manually with this brief:

- Size: 1024 x 500 px
- Visual direction: warm, calm, high-contrast
- Primary message: simpler Android home screen for seniors
- Supporting message: large buttons, caregiver setup, no clutter
- Suggested composition:
  - left: simplified branded icon or house motif
  - center/right: cropped device mockup showing the EasyUI home screen
  - short text overlay: "Simple phone home screen" or "Large buttons. Less clutter."
- Avoid:
  - tiny UI details
  - stock mockup overload
  - claims about full device lockdown
  - cloud or family-sync claims
