# Product Roadmap

## Phase 1 — MVP
Goal:
launch a stable senior-friendly launcher with obvious visual benefit.

Includes:
- launcher replacement
- large home interface
- simple app list
- emergency shortcut
- flashlight
- offline architecture

## Phase 2 — Caregiver Safety Pack
Goal:
add the features buyers are most likely to pay for.

Includes:
- PIN-protected editing
- app hiding
- layout lock
- pinned photo contacts
- restore/reset tools
- caregiver setup improvements

## Phase 3 — Dedicated Device Edition (future, separate track)
Goal:
explore deeper control only in valid managed-device scenarios.

Possible future direction:
- device-owner mode
- dedicated-device deployments
- stronger restrictions for controlled environments

Important:
This is not part of the core consumer promise and should be treated as a separate future edition if pursued.
