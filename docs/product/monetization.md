# Monetization

## Model

Freemium with a one-time premium unlock.

## Why

The buyer is usually a caregiver who wants a trustworthy utility, not a power user looking for a stream of new monthly features. A one-time purchase is easier to understand and easier to trust.

## Free tier

- senior-friendly launcher
- large icons and labels
- simplified app list
- flashlight shortcut
- emergency call shortcut
- basic theme option

## Premium tier

- PIN-protected caregiver mode
- layout lock
- hide apps
- pinned photo contacts
- backup and restore layout
- premium visual options
- caregiver setup tools

## Avoid at launch

- recurring subscriptions
- ad-heavy monetization
- confusing upgrade structure
