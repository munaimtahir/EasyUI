# Project Overview

EasyUI Senior Launcher is an Android launcher designed to make smartphones easier for seniors to use and easier for caregivers to maintain.

The product centers on a simple principle: make the phone easier to see, easier to understand, and harder to accidentally disrupt.

## Problem space

Many seniors struggle with modern Android home screens because they are visually dense and easy to change by mistake. Common failure cases include:

- moved or deleted icons
- cluttered app surfaces
- difficulty reading labels
- accidental entry into confusing apps or settings
- repeated caregiver support

## Core solution

Replace the normal Android home screen with a launcher that provides:

- large targets
- clear labels
- simple app access
- caregiver-protected editing
- optional app hiding
- emergency and direct-call shortcuts

## Philosophy

- simplicity before power
- stability before customization
- trust before growth hacks
- caregiver-first setup
- offline-first architecture
- honest technical boundaries

## Non-goals

- full device lockdown
- enterprise kiosk positioning
- cloud account dependency
- remote caregiver management for MVP or v1
