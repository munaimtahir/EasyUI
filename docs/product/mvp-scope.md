# MVP Scope

## Objective

Ship a useful senior launcher quickly with a clearly simpler experience than the default Android home screen.

## Must-have features

### Launcher replacement

- app can be set as the device home launcher
- first-run guidance explains how to set it as default

### Simple home screen

- large icon tiles
- large text labels
- high contrast design
- clean spacing
- minimal clutter

### Simple app access

- straightforward app list
- alphabetical sorting
- no folders
- no complex widgets

### Essential actions

- flashlight shortcut
- emergency call shortcut
- direct-call area for important contact(s)

### Offline-first behavior

- no account required
- no cloud sync required
- fully usable offline

### Accessibility basics

- large font support
- strict contrast
- simple theme options
- forgiving touch targets

## Explicitly out of MVP

- notification shade blocking
- true system lockdown
- device-owner mode
- remote caregiver control
- backend account system
- subscriptions
- ads
