# Project Brief

## Product name

EasyUI Senior Launcher

## One-line description

A simple Android home screen for seniors, with caregiver controls that reduce confusion and accidental changes.

## Core problem

Modern Android phones are visually dense and easy to disrupt accidentally. Seniors may tap the wrong item, move icons by mistake, struggle to read labels, or get lost in app clutter. That creates frustration for the senior user and repeated support burden for caregivers.

## Core solution

Provide a replacement launcher that:

- shows only what matters
- uses large buttons and clear text
- keeps layout stable
- lets caregivers lock editing and hide confusing apps

## Primary user

Older adults who need a simpler interface and lower risk of accidental disruption.

## Primary buyer

Adult children, caregivers, and family members who set up and maintain the device.

## Main user value

- easier phone use
- less confusion
- bigger, clearer controls
- easier calling of important contacts

## Main buyer value

- fewer support calls
- cleaner setup
- stable phone experience
- peace of mind

## Success condition

The caregiver can configure the phone once, hand it over, and receive fewer support calls because the layout stays stable and the daily interaction is clear.
