# Product Roadmap

## Phase 1: MVP

Goal: launch a stable senior-friendly launcher with obvious visual benefit.

Includes:

- launcher replacement
- large home interface
- simple app list
- emergency shortcut
- flashlight
- offline architecture

## Phase 2: Caregiver Safety Pack

Goal: add the features buyers are most likely to pay for.

Includes:

- PIN-protected editing
- app hiding
- layout lock
- pinned photo contacts
- restore and reset tools
- caregiver setup improvements

## Phase 3: Dedicated Device Edition

Goal: evaluate deeper restrictions only as a separate future managed-device track.

Possible future direction:

- device-owner mode
- dedicated-device deployments
- stronger restrictions for controlled environments

This is explicitly outside the consumer launcher promise.
