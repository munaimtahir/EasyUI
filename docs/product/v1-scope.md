# Version 1 Scope

## Goal

Add the caregiver features that justify payment and create a stable long-term product.

## Recommended v1 features

### Caregiver safety controls

- PIN-protected edit mode
- lock icon positions
- prevent accidental rearrangement
- optional disable long-press editing
- hidden caregiver entry from home
- caregiver-only settings area outside the normal senior flow

### App visibility control

- hide unused or confusing apps
- show only selected apps on home or app list
- optionally hide settings from normal view
- separate `Home Apps` management from senior-facing `All Apps`
- assign home apps to a bounded page and slot model

### Contacts and quick access

- pinned photo contacts
- direct-call family or doctor tiles

### Stability tools

- layout backup and restore
- restore default layout
- caregiver reset tools

### Interface options

- light theme
- dark theme
- battery visibility toggle
- simple attention indicator styling

## Nice to have if capacity allows

- medication reminder shortcut integration
- missed-call visibility on home
- larger dialer shortcut area
- caregiver onboarding wizard
